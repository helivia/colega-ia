# Colega.IA

Plataforma onde empresas personalizam seus assistentes virtuais.
Estado atual: as respostas dos chats são SIMULADAS (não há IA real), sem login funcional e sem banco de dados.

## Como abrir
1. Extraia o zip (Extrair tudo) e abra a pasta `colega-ia` no VS Code (File > Open Folder).
2. Dê dois cliques em `index.html`.

## Onde fica cada coisa (tudo dentro da pasta colega-ia)
- `index.html`: o conteúdo da página.
- `css/style.css`: a aparência.
- `js/personagens.js`: os desenhos das personagens (e o ajudante para personagens com imagem).
- `js/demo.js`: personalização e chat de demonstração.
- `js/ellie.js`: a Ellie, no canto da página.
- `img/personagens/`: as imagens PNG das personagens novas.
- `_backup/`: o arquivo original, intacto.
